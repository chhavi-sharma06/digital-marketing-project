# Digital Marketing Project

## 📌 About the Project

This project demonstrates practical applications of digital marketing through email marketing, social media advertising, and WordPress content creation.

## 🎯 Project Objectives

- Understand the fundamentals of digital marketing
- Create an email marketing campaign using Mailchimp
- Create and understand a Facebook Ads campaign
- Develop SEO-friendly heading tags for blog posts
- Gain practical experience with digital marketing tools

## 🛠️ Tools Used

- Mailchimp
- Facebook Ads Manager
- WordPress
- Canva

## 📂 Project Activities

### 1. Email Marketing
Created an email marketing campaign for a blog post using Mailchimp.

### 2. Facebook Advertising
Created a Facebook Ads Manager campaign with one ad group containing one advertisement.

### 3. WordPress Blog
Created SEO-friendly heading tags for two blog posts.
